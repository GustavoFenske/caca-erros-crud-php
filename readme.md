# 🐛 Caça aos Erros — CRUD em PHP

Atividade desenvolvida para identificar e corrigir erros em um sistema CRUD utilizando PHP.

## 📌 Sobre o projeto

O exercício consiste na análise de um código de CRUD que apresenta problemas, buscando identificar suas causas e realizar as correções necessárias.

## 🛠️ Tecnologias

- PHP
- MySQL
- HTML
- CSS

## 🎯 Objetivo

Praticar identificação de erros, análise de código e resolução de problemas em aplicações PHP.
